# HOLO H MAHER

تطبيق ويب عربي تجريبي بخمس تجارب: كوكب تفاعلي، خدع بصرية، كاميرا، مستجيب للصوت، وجسيمات.

## النشر على GitHub Pages
1. فك ضغط الحزمة.
2. ارفع الملفات الأربعة إلى جذر المستودع `HOLO-H-MAHER`.
3. من Settings ثم Pages اختر Deploy from a branch.
4. اختر `main` والمجلد `/(root)` ثم Save.
5. بعد اكتمال النشر افتح `https://mahercasper3-ai.github.io/HOLO-H-MAHER/`.

الكاميرا والميكروفون يحتاجان HTTPS وإذن المستخدم. تأثير الكاميرا إطار على الشاشة وليس إسقاطاً حقيقياً أو تتبعاً للجدران. هذا إصدار PWA وليس APK أصلياً بعد.
